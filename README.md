# Kameti.cash (v1, pre-hackathon version)

Interest-free rotating savings circle on Bitcoin Cash. No custody, no fees.

This repository is the version created BEFORE the BCH BLAZE 2026 hackathon (started 20 Oct 2026).
It contains only the circle logic, the create-circle form, the payout schedule and the share link.
